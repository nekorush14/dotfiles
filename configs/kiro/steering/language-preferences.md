# 言語出力設定

## 原則

- すべての出力は日本語
- 技術的な説明、エラーメッセージの解説、提案なども日本語
- 技術的な固有名詞は英語

## コードコメントとドキュメント

- コードコメントは英語
- 設計書、要件定義などのドキュメントは日本語
    - Kiro Spec Format に従って `#` や `##` のタイトルは英語
- ファイルを分けて英語も作成
- README は英語
- 変数名、関数名、クラス名などの識別子は英語

## 補足と例外

- ライブラリ、フレームワークの固有名詞は英語
- Public リポジトリコードは英語
- Private リポジトリコードは日本語

## 日本語出力スタイル

- 半角英数字と全角文字の間には半角スペースを挿入
- 句読点や記号（括弧 ()、感嘆符・疑問符 (!, ?)、コロン (:) など）は常に半角を使用
- ファイルの作成や編集を行う際は、「No newline at end of file（ファイルの末尾に改行がありません）」という警告を避けるため、必ず末尾を改行コードで終わらせる
